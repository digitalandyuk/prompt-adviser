- [prompts.chat](https://github.com/f/prompts.chat): prompt data CC0 1.0; site code and authored content MIT. Source and licence stated in its README.
- [MrXie23 PromptLibrary](https://github.com/MrXie23/PromptLibrary): README states MIT; no root licence file was found in the inspected repository. Use for discovery; verify individual prompt rights before excerpting.
- [OpenAI Cookbook](https://github.com/openai/openai-cookbook): MIT licence. Useful image, video and API examples. Its Sora 2 guide is archived, so current controls need verification.
- [Anthropic Claude Quickstarts](https://github.com/anthropics/claude-quickstarts): MIT licence. Useful computer-use examples.
- [Anthropic Claude Cookbooks](https://github.com/anthropics/claude-cookbooks): MIT licence. Useful Claude examples.
- [TypeSafe Jev documentation](https://docs.typesafe.ai/): linked documentation, not bundled or relicensed. Jev is a hosted service with separate terms and pricing.

Generic video-prompt structure in this release is original wording. A broader video prompt library can be added once its provenance, licence and quality are verified.
