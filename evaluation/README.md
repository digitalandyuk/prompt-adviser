# Repeatable task comparison

`cases.json` contains five fictional, self-contained tasks covering research, image prompts, video prompts, coding and computer-use planning. Each has a rough and a curated structured prompt with the **same supplied facts**, plus outcome criteria. The structured prompts illustrate the adviser's design principles; they are authored fixtures, not automatically generated adviser outputs.

Run `python3 evaluation/run.py --output /tmp/prompt-adviser-evaluation` with an authenticated Codex CLI. This creates ten independent, ephemeral, read-only sessions with the same CLI invocation, requesting its default model without user configuration. It does not pin or change a model, use the reviewed apps, generate media, buy API usage or run the returned code. Record the actual model/version separately when available; otherwise leave it unverified. The runner records final outputs, usage where returned and elapsed time. Set `--repeats 2` or higher for repeated samples; this consumes the account's normal model allowance. No run happens on install or CI.

Inspect each output against its case criteria. Use a transparent per-criterion pass/fail/unclear record; retain failures, and distinguish facts provided to the model from missing facts. For coding, execute returned functions against the specified normal and boundary inputs separately. For media, these tasks assess prompt specifications, not generated images/video. For computer use, assess the plan, not successful interaction with an actual UI.

The prompt variants run separately, with no access to each other's answers, and alternating order across repeats. This is a small task-output smoke comparison. It does **not** evaluate the complete adviser interview, user effort, native Claude/Antigravity, real research accuracy, media quality, app compatibility or statistical performance. Run the multi-turn review scenarios in `tests.md` separately. Before making an improvement claim, repeat with representative real tasks, native hosts, blind grading and equivalent scope/evidence. Report regressions as well as averages. Observed CLI token usage is not proof of billed cost or savings.
